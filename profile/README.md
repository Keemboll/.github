# Keemboll

**Open-source projects for the BI community — modeling, analytics engineering, governance and delivery.**

Keemboll is a home for practical, well-documented Business Intelligence projects. The name nods to the dimensional-modeling tradition popularized by Ralph Kimball: solid foundations first, then speed. The spelling is deliberately different — we build on that heritage, we don't claim it.

Each project is small, focused and independently usable. Together they cover the BI lifecycle: **design → model → build → verify → deliver → operate**.

## Principles shared by every project

- **Model first.** A clean semantic model beats a clever visual.
- **Verified, not just generated.** Code, DAX, TMDL, SQL and docs must be checkable.
- **Governance is part of delivery**, not an afterthought.
- **Tool-agnostic where possible.** Plain-text artifacts, open licences, no lock-in to a single vendor or agent.
- **Documented by default.** A project without a clear README and examples is not finished.
